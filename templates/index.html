Từ báo cáo mã độc đến kế hoạch xử lý

IR Workspace giúp bạn đọc báo cáo Any.Run, tìm dấu hiệu xâm nhập và xây dựng các bước ứng cứu có dẫn chứng. Bắt đầu với báo cáo có sẵn hoặc dùng dữ liệu mẫu để hiểu cách làm.

Bản web dùng thử. Hồ sơ và lịch sử trên máy chủ chỉ được lưu tạm, có thể mất khi hệ thống khởi động lại. Hãy tải báo cáo sau khi xem xét. Ghidra cần chạy bản trên máy tính.

Bạn đã có báo cáo?

Tải tệp Results.md hoặc JSON xuất từ Any.Run. Không cần API key khi nhập báo cáo có sẵn.

Lần đầu sử dụng?

Mở một ca WannaCry mô phỏng để xem kết quả, dẫn chứng và quy trình xử lý. Không cần tải tệp hay cấu hình.

Một hồ sơ đi qua 4 bước

Chưa có dữ liệu. Bắt đầu bằng một báo cáo hoặc dữ liệu mẫu.

  1. Chọn dữ liệu

    Nhập báo cáo, dùng liên kết Any.Run hoặc mở dữ liệu mẫu.

  2. Đọc kết quả & dẫn chứng

    Xem mức nguy hiểm, hành vi và IOC — các dấu hiệu cần kiểm tra.

  3. Xem xét khuyến nghị

    Đối chiếu bằng chứng, ghi người duyệt và lý do cho từng bước xử lý.

  4. Xuất & bàn giao

    Tải PDF để đọc, JSON để giữ dữ liệu hoặc quy tắc cho hệ thống giám sát.

Chương trình hỗ trợ phân tích và đề xuất. Bạn xem xét trước khi áp dụng; các lệnh khắc phục không tự chạy. Dữ liệu mẫu là mô phỏng.

Các chức năng dùng để làm gì?
Nhập dữ liệu
Đọc Results.md / JSON hoặc lấy báo cáo qua Any.Run. Gửi URL và tệp mới tới sandbox cần API key có quyền tương ứng.
Kết quả phân tích
Tóm tắt tệp, mức nguy hiểm, kết nối mạng, tiến trình và kỹ thuật MITRE ATT&CK được ghi nhận hoặc suy luận.
Chỉ báo & SIEM
Tra cứu IP, tên miền, URL và mã băm; xuất danh sách IOC hoặc mẫu truy vấn cho Splunk, Elastic, Sentinel, Sigma, Suricata và STIX.
Xem xét & xuất
Xem nguồn dẫn chứng, trao đổi với trợ lý điều tra, duyệt hoặc yêu cầu bổ sung khuyến nghị; tải báo cáo PDF, HTML, Markdown và JSON.
Lịch sử
Mở lại hồ sơ đã phân tích để tiếp tục xem xét. Lịch sử Any.Run cần API key; hồ sơ tạm trên bản web có thể mất khi máy chủ khởi động lại.
Ghidra trên máy
Phân tích tĩnh tệp bằng Ghidra khi chạy ứng dụng trên máy tính. Tệp không được thực thi trong quá trình phân tích tĩnh.

2. Kết quả phân tích

Chỉ báo, hành vi và mức ưu tiên xử lý.

Chưa có kết quả đang mở

Nhập báo cáo ở bước 1 hoặc dùng dữ liệu mẫu. Kết quả sẽ xuất hiện tại đây.

Đọc mức nguy hiểm trước, sau đó đối chiếu hành vi và chỉ báo bên dưới. Mở Chỉ báo & SIEM để xem từng IOC, hoặc chuyển đến quy trình để xem xét khuyến nghị.

Tiếp theo: đối chiếu chỉ báo và duyệt các bước xử lý.

1. Nhập dữ liệu

Chọn một nguồn dữ liệu để bắt đầu. Nhập báo cáo là cách đơn giản nhất.
Kết nối Any.Run bằng API key (tùy chọn)

Quản lý quyền truy cập task và gửi mẫu phân tích.

Lấy API Key ↗
Dán link app.any.run/tasks/…, any.run/report/… hoặc Task ID công khai. Không cần API key cho task công khai được Any.Run cho phép đọc.
Trang xem được trong trình duyệt vẫn có thể chặn yêu cầu tải từ máy chủ. Khi đó, dùng báo cáo Results.md/JSON đã xuất.

Chưa lấy được dữ liệu báo cáo

Trên Any.Run, chọn Export → Results (.md) hoặc JSON, rồi tải tệp ở đây. IOC JSON và thông tin bổ sung có thể để trống.

Submit & Phân tích ngay: tự động chờ sandbox xong rồi hiện kết quả (như main.py --url)
Submit (lấy UUID): chỉ lấy Task ID để dùng sau

Kéo thả file hoặc nhấn để chọn

.exe .dll .doc .pdf .zip ...

Submit & Phân tích ngay: upload file → sandbox phân tích → tự hiện kết quả (như main.py --file)
