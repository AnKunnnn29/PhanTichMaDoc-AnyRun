Chức năng & giới hạn
Nhập dữ liệu
Đọc Results.md / JSON hoặc lấy báo cáo qua Any.Run. Gửi URL và tệp mới tới sandbox cần API key có quyền tương ứng.
Kết quả phân tích
Tóm tắt tệp, mức nguy hiểm, kết nối mạng, tiến trình và kỹ thuật MITRE ATT&CK được ghi nhận hoặc suy luận.
Chỉ báo & SIEM
Tra cứu IP, tên miền, URL và mã băm; xuất danh sách IOC hoặc mẫu truy vấn cho Splunk, Elastic, Sentinel, Sigma, Suricata và STIX.
Xem xét & xuất
Xem nguồn dẫn chứng, trao đổi với trợ lý điều tra, duyệt hoặc yêu cầu bổ sung khuyến nghị; tải báo cáo PDF, HTML, Markdown và JSON.
Lịch sử
Mở lại hồ sơ đã phân tích để tiếp tục xem xét. Lịch sử Any.Run cần API key; hồ sơ tạm trên bản web có thể mất khi máy chủ khởi động lại.
Ghidra trên máy
Phân tích tĩnh tệp bằng Ghidra khi chạy ứng dụng trên máy tính. Tệp không được thực thi trong quá trình phân tích tĩnh.
